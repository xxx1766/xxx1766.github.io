TRPO 深度解析：从数学原理到代码实现

一、问题背景：为什么需要 TRPO？

强化学习的目标是不断更新策略参数 θ，使累计奖励最大化。最朴素的做法是直接做梯度上升：

θ←θ+α∇θ​J(θ)

但这有一个致命问题：步子太大会摔跤。一次更新过大，新策略可能远比旧策略差，而且强化学习没有”后悔药”——坏策略采集的数据质量更差，训练可能一路崩塌。

TRPO 的解决思路是：在每次更新时，显式限制新旧策略的差距不超过 ϵ：

θmax​Et​[πθold​​(at​∣st​)πθ​(at​∣st​)​At​]s.t.Es​[DKL​(πθold​​(⋅∣s)∥πθ​(⋅∣s))]≤ϵ

注意约束中有 Es​[⋅]：KL 散度对所有可能出现的状态 s 取期望，保证在整个状态分布上策略变化都不过大。

二、目标函数拆解

策略参数 θ

θ 是神经网络（策略网络）的全部权重和偏置。策略网络输入状态 s，输出动作的概率分布 πθ​(⋅∣s)。

在语言模型场景中，st​ = “原始问题 + 已生成的前 t 个 token”，at​ = “第 t+1 个 token 的选择”。

重要性采样比率

rt​(θ)=πθold​​(at​∣st​)πθ​(at​∣st​)​

我们用旧策略 πθold​​ 采集数据，但希望估计新策略 πθ​ 的表现。重要性采样的核心等式：

Ea∼πθold​​​[rt​(θ)⋅f(a)]=Ea∼πθ​​[f(a)]

  • rt​>1：新策略比旧策略更倾向选这个动作
  • rt​<1：新策略比旧策略更不倾向选这个动作
  • rt​=1：两个策略对此动作概率相同

优势函数 At​

At​=Q(st​,at​)−V(st​)

符号 含义
Q(st​,at​) 在状态 st​ 执行动作 at​ 后的期望累计奖励
V(st​) 在状态 st​ 下，按当前策略执行的期望累计奖励（基线）
At​>0 这个动作比平均水平好，应该强化
At​<0 这个动作比平均水平差，应该抑制

减去基线 V(st​) 不改变梯度的期望值（因为 Ea∼πθ​​[V(st​)]=V(st​) 与动作选择无关），但能大幅降低方差，让训练更稳定。

对时间步 t 取期望

Et​[⋯]≈T1​t=1∑T​(⋯)

等价于对一条（或一批）轨迹中所有时间步求平均，用来估计期望值。

三、KL 散度约束与二阶泰勒展开

KL 散度的定义

对于离散分布：

DKL​(p∥q)=a∑​p(a)logq(a)p(a)​

对于连续分布：

DKL​(p∥q)=∫p(x)logq(x)p(x)​dx

性质：

  • DKL​(p∥p)=0（自己与自己的散度为零）
  • DKL​(p∥q)≥0 恒成立（由 Jensen 不等式保证）
  • 不对称：DKL​(p∥q)=DKL​(q∥p)（一般情况下）

对 KL 散度做二阶泰勒展开

设 δ=θ−θold​，在 δ=0 处展开 DKL​(πθold​​∥πθold​+δ​)：

DKL​(πθold​​∥πθold​+δ​)=零阶项=0DKL​​δ=0​​​+一阶项=0∇δ​DKL​​δ=0⊤​δ​​+二阶项21​δ⊤Fδ​​+O(∥δ∥3)

零阶项 = 0

DKL​(πθold​​∥πθold​+δ​)​δ=0​=DKL​(πθold​​∥πθold​​)=a∑​πθold​​(a∣s)logπθold​​(a∣s)πθold​​(a∣s)​=0

一阶项 = 0（完整推导）

对 DKL​(πθold​​∥πθ​) 关于 θ 求梯度：

∇θ​DKL​(πθold​​∥πθ​)=∇θ​a∑​πθold​​(a∣s)logπθ​(a∣s)πθold​​(a∣s)​=−∇θ​a∑​πθold​​(a∣s)logπθ​(a∣s)

=−a∑​πθold​​(a∣s)⋅πθ​(a∣s)∇θ​πθ​(a∣s)​

在 θ=θold​ 处，πθ​=πθold​​，代入：

∇θ​DKL​∣θ=θold​​=−a∑​∇θ​πθ​(a∣s)​θ=θold​​=−∇θ​=1, ∀θa∑​πθ​(a∣s)​​​θ=θold​​=0

由于概率归一化 ∑a​πθ​(a∣s)=1 对任意 θ 成立，其关于 θ 的梯度恒为零向量。

二阶项：从一维到多维

一维情形：f(x0​+δ)≈f(x0​)+f′(x0​)δ+21​f′′(x0​)δ2

多维推广：

f(θ0​+δ)≈f(θ0​)+∇f(θ0​)⊤δ+21​δ⊤H(θ0​)δ

其中 Hessian 矩阵的元素为 Hij​=∂θi​∂θj​∂2f​，描述各参数方向上的曲率。

对 KL 散度而言，这个 Hessian 恰好等于 Fisher 信息矩阵 F（见下节证明）。

三阶项的形状

61​i,j,k∑​Tijk​δi​δj​δk​,Tijk​=∂θi​∂θj​∂θk​∂3f​

p 阶项的一般规律：系数 p!1​ 乘以 p 阶张量与 δ 的 p 次缩并。TRPO 忽略三阶及以上项。

四、Fisher 信息矩阵

定义

F(θ)=Es∼ρ,a∼πθ​(⋅∣s)​[∇θ​logπθ​(a∣s)∇θ​logπθ​(a∣s)⊤]

其中 ∇θ​logπθ​(a∣s) 称为 score 函数（得分函数）。F 是 score 函数外积的期望，是一个 n×n 的半正定矩阵。

对数导数技巧

∇θ​logπθ​(a∣s)=πθ​(a∣s)∇θ​πθ​(a∣s)​

这是策略梯度定理的核心变换：将”对概率求梯度”转化为”对对数概率求梯度”，数值上更稳定，且便于利用 Ea∼πθ​​[⋅] 进行期望计算。

Fisher 矩阵 = KL 散度的 Hessian（证明）

对 DKL​(πθold​​∥πθ​) 关于 θ 求二阶导，在 θ=θold​ 处：

Hij​=−∂θi​∂θj​∂2​a∑​πθold​​(a∣s)logπθ​(a∣s)​θ=θold​​

=a∑​πθold​​(a∣s)⋅∂θi​∂logπθ​(a∣s)​⋅∂θj​∂logπθ​(a∣s)​​θ=θold​​=Fij​

同时有等价形式（利用 score 函数期望为零推导）：

F=−Ea∼πθ​​[∇θ2​logπθ​(a∣s)]

自然梯度

在 KL 约束 21​δ⊤Fδ≤ϵ 下最大化线性目标 g⊤δ（g=∇θ​J(θ) 为策略梯度），用拉格朗日乘子法：

L(δ,λ)=g⊤δ−λ(21​δ⊤Fδ−ϵ)

∂δ∂L​=g−λFδ=0⇒δ∗=λ1​F−1g

步长由约束 21​δ∗⊤Fδ∗=ϵ 确定，解得 λ1​=g⊤F−1g2ϵ​​，最终：

δ∗=g⊤F−1g2ϵ​​F−1g​

这称为自然梯度方向，考虑了参数空间的黎曼曲率，比普通梯度方向更高效。

为什么 Fisher 矩阵很贵

网络规模 n 存储 F 求逆 F−1
小型 MLP 104 400 MB 可行但慢
中型策略网络 106 ≈ 4 TB 不可行
大语言模型 109 ≫ PB 完全不可行

这正是 TRPO 需要共轭梯度法的根本原因。

五、共轭梯度法求解 F−1g

关键洞察

我们要的不是整个逆矩阵，只是一个向量 x=F−1g，等价于求解线性方程组：

Fx=g

共轭梯度法（Conjugate Gradient, CG）专门解 Ax=b 这类对称正定线性方程组（Fisher 矩阵恰好满足这一条件），且有超强性质：

只需要能计算”F 与某向量 v 的乘积 Fv“，不需要显式存储 F

CG 迭代 k 步即可（k≪n），总计算量 O(kn)。

Hessian-Vector Product（HVP）

利用自动微分，Fv 可以通过两次反向传播计算：

Fv=∇θ​[(∇θ​DKL​(πθold​​∥πθ​))⊤v]

步骤：

  1. 前向传播，计算 DKL​
  2. 第一次反向传播：得到 gKL​=∇θ​DKL​（需要 create_graph=True 保留计算图）
  3. 计算标量 s=gKL⊤​v
  4. 第二次反向传播：∇θ​s=Fv

全程只需 O(n) 内存，完全可行。

方法 存储 计算复杂度
显式存储并求逆 F−1 O(n2) O(n3)
共轭梯度 + HVP O(n) O(kn)，k≪n

六、TRPO 伪代码逐行解析

nn.Module 是 PyTorch 所有神经网络的基类，提供参数管理、保存/加载等功能。super().__init__() 必须调用，否则参数追踪机制不会生效。

计算一批状态上的平均 KL 散度：

DˉKL​=∣B∣1​s∈B∑​DKL​(πθold​​(⋅∣s)∥πθ​(⋅∣s))

.mean() 对 batch 内所有状态取平均，对应约束中的 Es​[⋅]。

参数 数学符号 形状
states {st​} [batch, state_dim]
actions {at​} [batch]
advantages {At​} [batch]
old_log_probs ${\log\pi_{\theta_\text{old}}(a_t s_t)}$
max_kl ϵ 标量，默认 0.01

Step 1：计算当前策略分布

  • logits：网络输出原始得分，形状 [batch, action_dim]
  • Categorical：内部执行 softmax，将 logits 转成合法概率分布：

πθ​(a∣s)=∑a′​eza′​eza​​

  • log_prob(actions)：取出实际执行动作的 logπθ​(at​∣st​)，形状 [batch]

用 logits 而非直接输出概率，是因为 softmax 内部做了数值稳定处理（log-sum-exp trick），避免概率连乘下溢到 0。

Step 2：计算重要性采样比率

对应公式 rt​(θ)=πθold​​(at​∣st​)πθ​(at​∣st​)​，利用对数性质：

rt​(θ)=exp(logπθ​(at​∣st​)−logπθold​​(at​∣st​))

先减后 exp，比直接相除数值更稳定（避免两个极小概率相除产生数值爆炸）。

Step 3：计算代理目标函数

对应目标函数：

L(θ)=Et​[rt​(θ)⋅At​]≈∣B∣1​t∑​rt​(θ)⋅At​

为什么取负号？

PyTorch 的优化器只做梯度下降（最小化），而我们想最大化 L(θ)：

θmax​L(θ)⟺θmin​−L(θ)

类比：你想找山顶，但手里只有”下坡工具”——把地图翻转，让山顶变谷底，下到谷底就等于爬上了山顶。强化学习里凡是要最大化的目标，在代码中均加负号。

Step 4：计算梯度并展平

  • torch.autograd.grad：手动触发反向传播，返回 g=∇θ​L(θ)
  • create_graph=True：保留计算图，使后续可对梯度再次求导（HVP 必需）

各层参数形状不同，展平操作将所有梯度拼成一个长向量：

g=​第一层权重gW1​vec​​​,第一层偏置gb1​​​​,第二层权重gW2​vec​​​,…​∈Rn

例如一个小网络：

Step 5（省略）：共轭梯度求解更新方向

这里要解：

Fd=g⟹d=F−1g

其中 F 通过 HVP 隐式使用（见第五节）。

得到更新方向 d 后，TRPO 还需做线性搜索（Line Search）：沿方向 d 找到满足以下两个条件的最大步长 α：

  1. KL 约束：Es​[DKL​(πθold​​∥πθ+αd​)]≤ϵ
  2. 目标提升：L(θ+αd)≥L(θ)

最终更新：θ←θ+αd

八、总结与对比

特性 普通策略梯度 TRPO
更新规则 θ←θ+αg θ←θ+αF−1g
步长控制 手动设置学习率 KL 约束自动确定
稳定性 容易崩塌 有理论保证单调提升
计算代价 低 O(n) 高 O(kn)，需 CG + HVP
实现难度 简单 复杂

TRPO 的核心贡献是将”策略更新不能太激进”这一直觉严格数学化，并给出可行的计算方案。其后继者 PPO 用更简单的裁剪目标函数近似实现了类似效果，成为目前最主流的策略优化算法：

LCLIP(θ)=Et​[min(rt​(θ)At​,clip(rt​(θ),1−ϵ,1+ϵ)⋅At​)]
